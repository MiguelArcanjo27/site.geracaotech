# 💻 Geração Tech

### Sua aventura no mundo da programação começa aqui! 🚀

O **Geração Tech** é um portal educacional desenvolvido para estudantes do ensino médio que desejam conhecer o universo da programação e da lógica computacional.

O projeto tem como objetivo apresentar conceitos fundamentais de programação de maneira simples, intuitiva e interativa, incentivando o desenvolvimento do raciocínio lógico e da criatividade.

## 🎯 Objetivo do Projeto

Facilitar o primeiro contato dos estudantes com a programação, oferecendo conteúdos introdutórios, exemplos práticos e recursos gratuitos para apoiar o aprendizado.

## ✨ Funcionalidades

- **Apresentação sobre programação:** introdução aos conceitos básicos e à importância de aprender a programar.
- **Primeiros passos:** explicação sobre lógica de programação, pseudocódigo e programação em blocos.
- **Execução de pseudocódigo:** interação com o usuário por meio de um exemplo prático que simula um algoritmo.
- **Projetos inspiradores:** apresentação de ideias de projetos que podem ser desenvolvidos por estudantes.
- **Recursos educacionais:** acesso a materiais, tutoriais, comunidades e plataformas de desafios.
- **Tema claro e escuro:** possibilidade de alternar entre os temas, com preferência salva no navegador.
- **Navegação interativa:** menu com indicação da seção atualmente visualizada.
- **Layout responsivo:** adaptação da interface para diferentes tamanhos de tela.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web:

| Tecnologia | Aplicação |
